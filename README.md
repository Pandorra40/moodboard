# Moodboard 2026

Un tracker d'humeur annuel minimaliste — notez votre humeur chaque jour de l'année en coloriant une case.

## Fonctionnalités

- Grille des 365 jours de l'année, organisée par mois
- 4 humeurs : rouge (mauvaise journée), marron (journée sans plus), bleu (bonne journée), jaune (excellente journée)
- Sauvegarde automatique dans le navigateur (localStorage)
- Tutoriel intégré à la première visite
- Design sombre, 100% responsive
- Zéro dépendance, zéro serveur requis

## Technologies

- HTML / CSS / JavaScript vanilla
- localStorage pour la persistance des données

## Lancer le projet

Ouvrir directement `index.html` dans un navigateur, ou via un serveur local :

```bash
python3 -m http.server 8080
```

Puis aller sur `http://localhost:8080`
